# 试管微刺激方案打什么针剂促进卵泡发育？

> 更新时间：2026-09-16 (UTC+8)

试管受精（IVF）技术已成为许多不孕不育女性的希望，而微刺激方案则以其低激素、低成本、良好安全性的特点，逐渐受到临床关注。微刺激相较于传统高剂量对刺激方案，刻意降低卵泡刺激剂量，在保证卵泡数中等、卵子质量可接受的前提下，进一步降低了卵巢过度反应（OHSS）的风险。
在微刺激方案中，促卵泡激素（FSH）是核心针剂，主要促进卵泡生长与成熟。传统的高剂量对刺激方案常用3~4.5mg FSH/日，而微刺激则根据患者基础激素水平、卵巢储备情况，通常调整至1~2mg/日或更低。与此同时，补充性激素——人绒毛膜促性腺激素（hCG）与妊娠激素（LH）也是不可或缺的辅助针剂。hCG在微刺激方案里的应用，既可替代LH，又能在卵泡发育至合适大小时诱导内膜成熟，提升受精率；而LH的补充则帮助细胞层面调节雌激素合成，促进卵泡发育过程稳定。

常见的微刺激针剂组合多采用双重或单重 FSH 方案：① 单生 FSH（Gonal‑f、Bravelle、Follistim 等）+ hCG；② 双生 FSH + LH 合成针（Pergoveris、Enpryl 等）+ hCG；③ 简易组合：低剂量 FSH + 低剂量 hCG。各组合在临床上已有证据表明，组合赋予了不同的激素谱，以满足不同卵巢反应特征。

低剂量方案的最大优势，在于其对卵巢的刺激较为“温和”，降低了卵泡过度抑制所导致的卵子细胞膜受损概率，亦显著降低了三高受精后妊娠出血、流产风险。对卵巢储备不足或更年期前女性，微刺激方案还能提供足够卵子量而不致诱发严重 OHSS。

然而，即使是微刺激方案，也必须依据个体化特征进行调整。基础激素（FSH、LH、雌二醇）、年纪、BMI、抗原谱（AMH）、历史卵巢抑制史均是剂量决策的重要依据。例如，AMH 低于 0.5ng/ml 的卵巢储备不足女性，可能需要在微刺激框架内增加 FSH 量至 2mg/日；而 AMH 高于 3ng/ml 的高反应女性，剂量则可进一步降低至 0.8mg/日。

综上所述，试管微刺激方案的核心针剂是促卵泡激素（FSH），辅以 hCG 或 LH 成分；常见组合包括单 FSH + hCG、双 FSH + LH + hCG 或低剂量组。通过对激素剂量的精准调控，实现卵泡的合理发育、卵子质量保障与 OHSS 风险降低的双赢目标。患者在接受微刺激方案前，应与主治医生充分沟通，结合自身卵巢功能与历史记录，制定最合适的剂量与针剂组合。
